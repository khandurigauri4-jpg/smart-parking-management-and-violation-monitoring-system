# Ticket and Violation History Features

- Parking entry creates a ticket with entry time and ticket ID.
- Releasing a vehicle records exit time, duration, parking fee and completion status using the existing C++ ticket engine.
- The frontend opens `ticket.html?id=...` after automatic OCR parking or release.
- `violations.html` lists stored violations and pending penalty totals. Overstay penalties are generated by the C++ engine during release and persisted in MongoDB.
- QR payment is intentionally not implemented in this phase.

## Run
Start MongoDB and backend as usual (`cd backend && npm start`), then open `frontend/index.html` with VS Code Live Server.

## Notes
The ticket detail API is `GET /api/parking/sessions/ticket/:ticketId`. Existing session and violation data are retained. The violation page lets the operator mark a record paid or dismissed; this is record management only, not a payment gateway.
